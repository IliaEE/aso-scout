# ASO Scout

Автономный сборщик кандидатов для ASO-ниш. Сервер сужает тысячи запросов до
нескольких десятков, человек с Astro подтверждает спрос.

## Идея в одном абзаце

Матрица «глагол × объект» **не генерирует запросы**. Она генерирует зонды для
автокомплита. Мы отправляем `scan`, Apple возвращает `scan pdf`,
`scan documents`, `scan receipts` — это уже валидированные запросы, потому что
автокомплит показывает только то, что люди реально вбивают. Сочетание
`scan blood pressure` не вернётся никогда, и в воронку не попадёт. Валидатор —
сама Apple, а не наш код.

## Как связываются запросы без LLM

Четыре детерминированные проверки, все на цифрах:

1. **Существование** — вернул автокомплит, значит запрос реален.
2. **Связность** (`pipeline/coherence.py`) — доля топ-10, у кого слова запроса
   стоят в названии. Настоящая ниша: по `scan pdf` в топе `PDF Scanner`,
   `Scan to PDF`. Бессмыслица: Apple отдаёт случайный набор, совпадение падает
   к нулю. Отсев по порогу.
3. **Дедуп** — `noise meter` / `noisemeter` / `noise metre` в один ключ.
4. **Кластеризация по пересечению выдачи** (`pipeline/cluster.py`) — если у двух
   запросов 8 из 10 приложений общие, Apple считает их одной потребностью.
   Кластеры собираются из индекса Apple, понимание смысла не требуется.

## Защита от мёртвых нишy

Главная опасность бесплатных данных: пустая ниша выглядит идеально по
конкуренции именно потому, что никому не нужна. Поэтому score — **произведение**,
а не сумма: `слабость × деньги × прокси-спроса × связность`. Любой множитель
около нуля обнуляет всё.

Тест это проверяет напрямую: у мёртвой ниши `weakness=0.7` (топ реально слабый),
но `money=0.0`, и итог 0.0 против 72.8 у настоящей. Наивная сумма дала бы ей
2.59 и подняла наверх.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env      # впишите контакт в USER_AGENT
python -m src.jobs.doctor # ОБЯЗАТЕЛЬНО перед первым сбором
```

`doctor` проверяет, не забанен ли egress IP у Apple. На shared-хостинге вроде
Railway IP может быть уже сожжён другими скрейперами, и тогда всё ниже по
потоку молча пустое. 30 секунд проверки против недели напрасного сбора.

## Использование

```bash
# Широкий скан: 2 запроса на глагол, много глаголов
python -m src.jobs.collect --store us --limit-roots 12

# Глубокое бурение одной ниши: a-z суффиксы, 28 запросов на корень
python -m src.jobs.collect --roots noise decibel --deep

# Отчёт (то, что вы видите в понедельник)
python -m src.jobs.report

# Промпт кластера для кандидата №1 — вставить в Claude
python -m src.jobs.report --prompt 1
```

На Mac, когда удобно:

```bash
python -m src.astro.dump --inspect            # схему Astro — в первый раз
python -m src.astro.dump --out facts.json     # выгрузить факты
python -m src.astro.dump --load facts.json    # загрузить в базу скаута
```

## Недельный цикл

1. **Понедельник, телефон, 5 мин** — `report`, отсеять мусор.
2. **Ноутбук, 30 мин** — `--prompt N` в Claude, получить кластер, вставить в Astro.
3. **Через 5–7 дней, 20 мин** — `dump --out`, `dump --load`, промпт вердикта.

Вердикт даёт шесть исходов, и только один окончательный: GO, NO-GO,
СУЗИТЬ (голова мёртвая, TAIL живой), ДРУГОЙ СТОР, ADJACENT, HOLD.

## Railway

Postgres обязателен: файловая система эфемерная. Cron-сервис должен
завершаться, иначе Railway пропустит следующий запуск —
`restartPolicyType = "NEVER"` в `railway.toml` про это.

## Чего этот код не делает

- **Не измеряет спрос.** Бесплатных источников объёма нет. Прокси здесь
  порядковые: позиция в автокомплите и доля конкурентов, потративших символы
  метаданных на это слово. Они годятся только для сортировки кандидатов между
  собой. Настоящая цифра приходит из Astro.
- **Не заменяет ASA-валидацию.** Система находит место, где можно занять
  органику. Окупаемость проверяется рекламой на тонком MVP, не здесь.
- **Выдача iTunes API ≠ выдача App Store.** Это другой индекс. Годится для
  отсева тысяч, но топ-20 кандидатов проверяйте глазами или через Astro.
- **Оценка установок врёт систематически.** Приложения, агрессивно просящие
  оценку, выглядят крупнее. Сравнивать только внутри одной категории.
  Множитель в `Thresholds` — это догадка, которую надо калибровать.
- **Автокомплит недокументирован.** Может измениться или отвалиться без
  предупреждения. Поэтому таблица `suggestions` хранит весь сырой корпус: при
  отвале эндпоинта система продолжит работать на накопленном.
- **Не пишет в базу Astro.** Core Data ведёт свой учёт ключей в
  `Z_PRIMARYKEY` и `Z_METADATA`; вставка строк без их согласованного обновления
  ломает приложение. Ключи заводятся через интерфейс, руками.
